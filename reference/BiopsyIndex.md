# Index biopsy locations

This function returns all the conversions from common version of events
to a standardised event list, much like the Location standardidastion
function This does not include EMR as this is extracted from the
pathology so is part of pathology type. It is used for automated OPCS-4
coding.

## Usage

``` r
BiopsyIndex()
```
